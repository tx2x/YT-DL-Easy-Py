# YT-DL Easy Py v1.1.0

A quality-of-life update focused on clearer format selection and a smoother interactive workflow.

- **Easier audio selection:** audio tracks explicitly marked `original` or `default` by yt-dlp are highlighted with `★ ORIGINAL / DEFAULT`.
- **Clearer video codec identification:** AV1 (`av01`), H.264 (`avc1`), and VP9 (`vp9`) formats now have distinct labels.
- **Repeat downloads:** after each session, choose to start another download without relaunching the program. Press Enter to exit (default).

The underlying yt-dlp format rows and format IDs remain unchanged. Original/default highlighting is shown only when yt-dlp exposes that information.

See `README.md` for installation and usage instructions, and `CHANGELOG.md` for the complete change history.
